# Pocket Desktop iOS refinement plan

Goal: improve the desktop interaction for iPhone 16, 17, and 18 generation devices and make simulator testing possible. This is an iOS app workspace; iOS does not permit it to host other installed apps.

1. Add independently tested geometry for resizing from all eight edges/corners, snapping to left/right, and calculator keyboard behavior.
2. Hook pointer, keyboard, and touch interactions to the window manager; default the native application to landscape.
3. Replace the native app's embedded iframe browser with a separately hosted native web view, without weakening transport security. Keep a clear fallback for browser-only previews and sites that reject in-app browsers.
4. Add repeatable automated iOS Simulator tests and a GitHub Actions workflow. Record exactly which simulators and test cases actually run.
5. Validate locally available checks, describe the remaining need for iOS Simulator/physical input and display tests, and save the updated project.

Review focus: geometry near viewport limits; loss of native browser clipping or focus; system-owned orientation/input constraints; privacy of the native bridge; distinguish tests configured from tests run.

Status: Local core, WebKit/Firefox interaction and WebKit mobile viewport tests passed. Native simulator execution and physical peripheral testing remain blocked pending an accessible macOS runner.
